# Contributing

Corrections and additional questions are welcome. Open an issue with a chapter/question ID, the current claim, the proposed correction, and a primary reference or a minimal counterexample. Include hardware and software versions for implementation-specific behavior.

For a new question, provide: difficulty; prerequisite knowledge; a precise question; an answer with assumptions; a common mistake; and further reading. Keep worked calculations distinct from measured experiments. Include raw methodology and environment details for any new measurement.

Edit Markdown chapters and rebuild the static pages. Do not copy private source notes, credentials, unreviewed images, or proprietary architecture into a contribution. Cite public implementations rather than silently reproducing their code.
